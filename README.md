# Pixel House

고양이 집사 **두부**와 함께 사는 작은 픽셀 원룸. 물·잠·식사·약속·독서 같은 생활 기록을 **내 컴퓨터의 파일 하나**에 남기는 맥 앱입니다.

- 서버도 계정도 없습니다. 앱은 인터넷에 연결하지 않고, 기록은 내가 고른 폴더의 마크다운 파일(`PixelHouse_생활기록.md`) 하나에만 남습니다.
- 두부는 정해진 대사로 말합니다. 평가하거나 재촉하지 않습니다.

## 할 수 있는 것

- 생활 습관: 오늘 체크(매일·주 n회·월 n회), 안전장치(주 1회 확인), 양 적기, 습관 더하기·고치기·지우기
- 집 안 가구에 붙은 기록: 물컵(물 한 잔), 침대(하루 마감), 냉장고(오늘 약속·장보기 메모), 벽 달력(약속), 책꽂이(독서), TV(영화·연극 기록), 탁자(식사 일지), 러그(요가), 책상(공부), 변기(대변 일지)
- 두부 대화창: 잠·식사·오늘 한마디 적기
- 약속 달력, 버킷리스트 메모지, 공부 계획 막대·잔디, 살림 인벤토리, 생활일지
- 집 꾸미기: 정해진 자리마다 가구 후보 고르기, 가구마다 붙는 기능 바꾸기 (집 오른쪽 위 "가구 기능 연동")

## 처음 실행

이름 -> 모습(아바타 3명) -> 집(원룸) -> 기록 폴더 -> 습관 순서로 두부가 물어봅니다.

- 기록 폴더 기본값은 `~/Documents/PixelHouse` 입니다. 다른 폴더를 골라도 됩니다.
- 고른 폴더에 기록 파일이 없으면 빈 틀을 만들고, 이미 있으면 그대로 이어서 씁니다.
- 고른 값은 앱 설정 폴더(`~/Library/Application Support/Pixel House/profile.json`)에 저장됩니다. 처음부터 다시 하려면 이 파일을 지우면 됩니다(기록 파일은 그대로 남습니다).

## 설치 (소스에서 실행)

필요한 것: macOS, [Node.js](https://nodejs.org) 20 이상

```sh
npm install
npm start
```

## 맥 앱 만들기

```sh
npm run dist:mac
```

`dist/` 폴더에 `.dmg`와 `.app`이 생깁니다.

### 서명하지 않은 앱 열기

이 앱은 애플 개발자 서명을 하지 않았습니다. 처음 열 때 macOS가 "확인되지 않은 개발자" 경고를 띄웁니다.

1. `Pixel House.app`을 **우클릭(또는 Control-클릭) > 열기**를 누릅니다.
2. 경고 창에서 다시 **열기**를 누릅니다. 한 번 열고 나면 그다음부터는 그냥 열립니다.

열기 버튼이 보이지 않으면: **시스템 설정 > 개인정보 보호 및 보안** 아래쪽의 "그래도 열기"를 누릅니다.

## 기록 파일

- 표 모양만 지키면 다른 편집기로 직접 고쳐도 됩니다. 앱은 파일이 바뀌면 다시 읽습니다.
- 앱이 쓰기 직전에 사본을 앱 설정 폴더 `backup/`에 남깁니다(최근 10개).

## 시험

```sh
npm test
```

계산 시험과, 실제 창을 띄워 온보딩 -> 입장 -> 가구 기능 -> 집 꾸미기를 따라가는 시험이 돕니다. 임시 폴더만 쓰고 끝나면 지웁니다.
